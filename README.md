Software Developer
------------------

I've been programming for ~9 years. I initially started out purely in game development, (Ren'Py, UE5, Unity, and from-scratch projects like Python platformers). After a few years, I had started to drift out of game development and into software development, mostly because of how limiting games felt to me. With a game, I always felt boxed into a set theme, a set idea, or a set atmosphere. Software felt different, however. It felt like I could build literally anything with no ceilings to hit. I also felt that there was a real chance it'd be something people actually found useful.

I got into this because I love the feeling of hitting keys on a keyboard and watching something spring to life. And I just love the idea of building something that is genuinely helpful, something that people actually need. Not just something that exists.

Thanks so much for reading! Feel free to take a look around!
